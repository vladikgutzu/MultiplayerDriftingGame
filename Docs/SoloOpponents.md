# Одиночные соперники

`BD_ModeSession` создаёт соперников только при `offlineMode`.

| Режим | Соперники и результат |
| --- | --- |
| Sprint / Circle | Три дорожных соперника; места по принятым контрольным точкам и порядку финиша. Карьерный босс остаётся отдельной дуэлью. |
| Drift | Три дрифт-соперника; за 120 секунд нужно набрать больше очков. Нулевой результат не считается победой. |
| CountDown | Три соперника; победа за достижение 10 000 очков раньше соперников и до окончания времени. |
| Tournament | Три соперника в трёх раундах; требования 4000 / 6000 / 8000 очков за раунд и первое место по сумме. |
| FreeRide | Три локальных водителя без обязательного финиша или победы. |
| Multiplayer | Локальные боты не создаются. |

Дрифт-очки рассчитывает обычный `BD_PlayerManager`: скорость, угол, длительность заноса, множитель и сброс при столкновении. AI не получает очки по таймеру, прогресс за телепортацию или деньги игрока. Ограниченная помощь удержания угла находится в `BD_DriftBot` и применяется только к ботам; контроллер игрока не изменён.

Машины создаются через `RaceCarsSpawnService.SpawnLocalOpponent`. Камеры, AudioListener и сетевые компоненты локальных соперников отключены; выбранная машина игрока, её сохранённые детали и камера не переназначаются. Если у локальной копии модели отсутствует связь дифференциала с осью, используется её существующая задняя ось. `BD_BotTuning` повышает тюнинг по числу завершённых заездов, начиная со стока.

Дорожные гонки используют `ModeRoutes`. Остальные режимы используют `Resources/SoloBotRoutes/<имя сцены>`. В маленькой дрифт-арене подбирается безопасная дуга; на просторных площадках — связанные левые/правые дуги с перекладками; в городе — дорожная петля. Подготовка маршрута проверяет поверхность, края дороги и препятствия в редакторе, а не во время загрузки игры. После изменения масштаба или геометрии карты маршрут нужно обновить.

## Сложность

В Options есть кнопка `AI: ... (NEXT RACE)`: мышь/касание/Submit переключают EASY → NORMAL → HARD → EXPERT. Значение сохраняется в `SoloBotDifficulty`; существующий enum `RaceDifficulty.Ease` соответствует надписи EASY. Выбор считывается при создании соперника и не меняет уже начатый заезд.

| Навык | Easy | Normal | Hard | Expert |
| --- | --- | --- | --- | --- |
| Интервал оценки препятствий | 0,24 с | 0,14 с | 0,085 с | 0,05 с |
| Целевой угол до физических ограничений машины | 22° | 24° | 28° | 32° |
| Намерение держать занос / пауза | 6 / 2,2 с | 7 / 1 с | 12 / 0,5 с | 20 / 0,2 с |
| Относительный дорожный темп | 0,76 | 1 | 1,1 | 1,2 |

Это параметры водителя, а не гарантированные углы или множители результата: сцепление, масса, мощность, столкновения и предел скорости на конкретной дуге сохраняют влияние. Прогрессивный механический тюнинг остаётся отдельной системой.

`BD_BotAwareness` использует физические проверки впереди, проверку свободного места сбоку и прогноз ближайшего сближения по относительной скорости. На пересечении траекторий есть устойчивый приоритет; при непосредственной угрозе тормозят все. При застревании дрифт-бот сначала проверяет пространство сзади и пробует выехать, а возврат к последней точке остаётся аварийной мерой. Нет скрытого ускорения для догоняния игрока и подстановки очков. Дым передних колёс у ботов ослаблен; эффект игрока не изменён.

В дорожной гонке обычный городской трафик возвращается в свой пул в пределах 20 м от стартовой решётки только во время отсчёта. Это исключает случайный спавн посторонней машины внутри участников до старта; остальной трафик не отключается. Ожидание свободного пути больше не переключает коробку в задний ход каждые две секунды: гоночный водитель отдельно проверяет возможность выезда и включает передачу один раз на попытку.

Команды редактора (без сборки):

```text
unity command bd_author_solo_bot_route --caller plugin --skill unity-cli --json
unity command bd_author_all_solo_bot_routes --timeout 180 --caller plugin --skill unity-cli --json
unity command bd_solo_opponents_check --mode Drift --seconds 25 --caller plugin --skill unity-cli --json
unity command bd_solo_modes_suite --caller plugin --skill unity-cli --json
unity command bd_bot_skill_checks --caller plugin --skill unity-cli --json
unity command bd_bot_visual_check --label Expert --difficulty Expert --caller plugin --skill unity-cli --json
unity command bd_solo_opponents_check --mode Sprint --seconds 12 --difficulty Ease --caller plugin --skill unity-cli --json
unity command bd_bot_difficulty_ui_check --caller plugin --skill unity-cli --json
```

`bd_solo_modes_suite` проводит несколько заездов в Play Mode и возвращает исходную сцену. Результаты и телеметрия сохраняются в `Temp/SoloModesSuite.txt` и `Temp/SoloOpponents_*.txt`. Визуальная проверка снимает настоящие кадры камерой, PNG и наблюдения находятся в `Temp/BotVisual/<label>`. Тестовые уровни не записывают выбор игрока. UI-проверка запускается из сцены Main Menu и восстанавливает исходное значение настройки. Перед переключением карт необходимо сохранить открытые сцены.
