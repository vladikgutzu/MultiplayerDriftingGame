# Технологии Multiplayer Drifting Game

## Основной стек

| Область | Технология |
|---|---|
| Движок | Unity 6000.4.7f1 |
| Язык | C# |
| Рендеринг | Universal Render Pipeline 17.4.0 |
| Асинхронность | UniTask |
| Ввод | Unity Input System 1.19.0 |
| Контент | Addressables 2.9.1 |
| Анимация | Animation Rigging 1.4.1 |
| UI | uGUI 2.0.0, DOTween-ориентированные переходы |

## Сетевая и платформенная часть

- Photon PUN/Realtime использовался для многопользовательских режимов и синхронизации сессий.
- Unity Multiplayer Center применялся для настройки и диагностики мультиплеера.
- Unity IAP 5.4.4 — инфраструктура внутриигровых покупок.
- Nintendo-ориентированные UI-контроллеры и пакет Input System для Switch присутствуют в исходной производственной версии.

## Архитектура приложения

- Конечный автомат состояний приложения: boot, главное меню и gameplay.
- Сервисная архитектура с синхронными и асинхронными `MonoBehaviour`-сервисами.
- Система сцен с командами загрузки, fade-переходами и ScriptableObject-каталогом.
- Pub/sub-события для слабой связанности игровых модулей.
- Пулы объектов, сохранение/загрузка и общая инфраструктура runtime-систем.
- ScriptableObject-конфигурации гонок, типов управления, сложности, точек старта и трасс.

## Игровые технологии

- Контроль гонок, чекпоинты, прогресс по маршруту и конструктор гоночных сессий.
- Сервисы спавна автомобилей и наборы управляющих пресетов.
- Настройка автомобиля: краска, диски, неон и цвет дыма.
- Риг водителя, цели рук и рулевого колеса.
- XP, прогрессия, здоровье, подбор предметов и дополнительные игровые режимы.
- URP Shader Graph для автомобильных материалов и визуальных эффектов.

## Инструменты

- Unity Recorder 5.1.6.
- AI Navigation 2.0.12.
- MyBox для удобных инспекторных инструментов.
- Rider и Visual Studio.
- Unity Test Framework 1.6.0.

## Портфолио-версия

Публичный репозиторий содержит авторские игровые системы и архитектуру. Лицензированные автомобили, трассы, Photon SDK, рекламные/аналитические SDK, Nintendo SDK, запечённое освещение и тяжёлые арт-паки исключены.
