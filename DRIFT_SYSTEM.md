# Дрифт-система

## Что изменено

`BD_DriftController` автоматически добавляется к каждой игровой машине через
`BD_PlayerManager`. Исходные prefab не требуют ручной настройки.

Контроллер работает поверх RCCP и выполняет четыре задачи:

1. Помогает начать занос при повороте с газом или ручником на скорости от 18 км/ч.
2. Удерживает направление, заданное игроком, вместо постоянного искусственного вращения.
3. Гасит избыточную угловую скорость по мере роста угла заноса.
4. После 38° постепенно возвращает боковое сцепление; около 55° включается полное
   восстановление, уменьшающее вероятность неконтролируемого разворота.

## Базовые параметры

| Параметр | Значение |
|---|---:|
| Минимальная скорость | 18 км/ч |
| Полная сила ассиста | 55 км/ч |
| Начало распознавания заноса | 7° |
| Завершение распознавания заноса | 4° |
| Предпочтительный максимальный угол | 38° |
| Угол полного восстановления | 55° |
| Усилие входа | 5.5 |
| Усилие удержания | 3.25 |
| Подавление разворота | 4.5 |
| Восстановление бокового сцепления | 7.0 |

## Интеграция с RCCP

- Включён штатный drift mode колёс.
- Включены counter steering, steering helper и traction helper.
- ESP и TCS отключаются, потому что они принудительно гасят powered oversteer.
- ABS остаётся включённым.
- Требуемые настройки повторно контролируются после старта: RCCP применяет выбранный
  behavior с задержкой и иначе мог снова выключить ABS/counter steering/drift mode.
- Старый постоянный поворотный момент из `BD_PlayerManager.FixedUpdate` удалён.
- Drift scoring использует реальный угол движения из нового контроллера.
- Порог выхода 4° ниже порога входа 7°, поэтому счётчик и эффекты не мигают при
  небольших колебаниях угла заноса.
- В сетевой игре физический ассист применяется только владельцем PhotonView.
- Исправлен prefab `SILVIA 15`: передняя ось снова рулит и тормозит, задняя ось
  снова использует рабочий тормоз и ручник. До исправления все четыре флага были
  выключены, поэтому эта машина объективно управлялась хуже остальных.

## Проверка парка машин

Editor-команда `Burnout Drift/Validate Drift Fleet` проверяет все машины из
`BD_PlayerCars`: RCCP/BD-компоненты, Rigidbody, минимум две оси и четыре колеса,
рулевую ось, ручник и подключённые дифференциалы. Эту же проверку можно запускать
без сборки методом `BD_DriftFleetValidator.RunBatch`.

## Следующая калибровка

Численные значения рассчитаны как безопасная базовая конфигурация для всех машин.
После живого прогона клавиатуры и геймпада следует отдельно уточнить три значения:
`entryYawAcceleration`, `spinDamping` и `recoveryGrip`. Они сериализованы и могут
настраиваться без изменения алгоритма.
