# Режимы игры

Цикл: практика в городе → очки и стабильность в дрифте → квалификация и
шесть соперников Blacklist → трёхраундовый Drift Cup. Спринт и кольцо дают альтернативу:
важна траектория и время, а не количество дрифт-очков.

## Реализованные правила

| Режим | Сцена | Условие завершения |
|---|---|---|
| FreeRide | CityDay / CityNight | Без таймера, тренировка |
| Drift | DriftTrack | Набрать максимум очков за 120 секунд |
| CountDown | DriftTrack | 10 000 очков за 120 секунд |
| Career | DriftTrack / CityDay | 6 рангов: квалификация по финишам, дорожным победам и дрифт-очкам; затем Sprint + Circle против босса |
| Tournament | DriftTrack | 3 раунда по 60 секунд: 4000 / 6000 / 8000 **новых** очков за раунд |
| Sprint | CityDay / CityNight | 11 точек по порядку за 180 секунд |
| Circle | CityDay / CityNight | 3 круга по 52 точкам за 300 секунд |
| Multiplayer | CityDay / CityNight | Существующий сетевой вход через комнаты; в рамках этой работы не изменён |

Спринт и кольцо — офлайн-гонки игрока против трёх AI-соперников.
Перед стартом общий отсчёт 3 секунды. Позиция определяется количеством
последовательно принятых точек и продвижением по текущему отрезку, а не
расстоянием до финиша по прямой. Финиш бота не завершает заезд игрока.
Остальные участники могут закончить раньше игрока; завершение маршрута
игроком даёт награду за прохождение и показывает реальное итоговое место.
Drift Cup остаётся дрифт-заданием на очки, без фиктивных AI-очков.
В дуэли карьеры один физический AI-босс; его финиш первым означает поражение.
Новые сцены не выдуманы: используются три имеющиеся игровые сцены.
CountDown поддерживается кодом (категория 8), отдельной точки на карте пока нет.

Карьера сохраняется в BlacklistCareerV1; старые CareerStageV1 и
CareerCompletedV1 читаются при первом запуске для переноса ранга.
После последнего босса карьера завершена, обычные режимы остаются доступны.
Награда/XP выдаются через существующую экономику один раз при успехе;
при поражении награды нет. В кубке награда только после финального раунда.
Личные рекорды ModeBestV1_* сохраняются только после успешного завершения:
лучшее время для дорожных режимов, лучший счёт для дрифт-режимов.

## Связь с меню и HUD

Выбор категории задаёт режим; кнопка старта выбирает подходящую сцену.
В карточках обновляются название, реальные правила, лимит времени и рекорд.
В игровом HUD отображается цель/раунд/круг/следующая точка; дорожные точки
помечаются зелёными воротами без физического коллайдера.
На результатах дорожных режимов показывается время, а не дистанция дрифта.
Показаны все четыре участника, времена финиша и DNF для не закончивших.

## Соперники

Используется существующий RCCP_AI и общий локальный спавн в
RaceCarsSpawnService. Режим directWaypointSteering ведёт физический автомобиль
по размеченным точкам без обязательной NavMesh; старые режимы AI сохранены.
BD_RaceOpponents отвечает за решётку, отсчёт, места и порядок финиша;
BD_RaceBot связывает независимый RaceWaypointProgress с вводом AI.

Локальные соперники не регистрируются как активная машина игрока, не получают
клавиатурный ввод, не начисляют игроку очки и не содержат Photon-синхронизации.
У них отдельные ограничения скорости, торможение перед поворотами, лучи
препятствий и объезд других участников. При застревании сначала работает
задний ход; при длительном отсутствии прогресса — возврат к последней
принятой точке (не к следующей), без бесплатного продвижения и финиша.
После завершения заезда управление соперниками отключается;
при смене сцены их объекты удаляются вместе с сессией.

Для ботов отключены унаследованные ESP/TCS (ABS сохранён): на некоторых
дрифт-префабах эти помощники полностью обрывали тягу при малой скорости
и повернутом руле. Игроку эта настройка не применяется. Локальные машины
защищены от последующей перезаписи выбранным глобальным RCCP-поведением.

### Постепенный тюнинг соперников

BD_BotTuning создаёт отдельный runtime-набор улучшений для каждого соперника.
Он не загружает и не сохраняет настройки выбранной машины игрока.
На локальных ботах отключены BD_ModApplier и скрипты BD_VehicleUpgrade_*,
которые при старте/активации могли читать или записывать общие ключи игрока.
Улучшения ботов применяются явно к их собственным экземплярам.

| Успешно завершено заездов | Максимальная ступень ботов |
|---|---|
| 0–2 | 0: сток, без спойлеров и замены дисков |
| 3–7 | 1: лёгкие улучшения, диски |
| 8–15 | 2: бамперы, выхлоп, спойлеры при наличии |
| 16–27 | 3: дополнительно капоты и пороги |
| 28–44 | 4: более развитые обвесы и расширители |
| 45+ | 5: верхняя ступень, ограниченные прибавки характеристик |

Первые три успешно проходимых заезда начинаются со стоковыми соперниками.
Один из трёх соперников остаётся на ступень ниже, чтобы весь состав не
получал одинаковый максимальный набор. Используются только имеющиеся детали;
отсутствующие менеджеры/варианты пропускаются. Обязательные кузовные панели
сохраняют штатный вариант 0; необязательные спойлеры в начале скрыты.
Неон, полицейское оборудование и наклейки игрока ботам не копируются.

Мощность увеличивается относительно собственной базовой машины максимум
на 25%, тормоза — на 40%, усилие стабилизаторов — на 20%.
Базовая разница между автомобилями сохраняется; настройки игрока не меняются.
Набор фиксируется при спавне и не усиливается посреди заезда.

Счётчик PlayerCompletedRacesV1 растёт один раз в FinishRace, кроме FreeRide.
Поражения, перезапуски, чужие финиши и повторный FinishRace его не увеличивают.
Он сохраняется между запусками. Для прежних сохранений начинается с нуля:
купленный или накопленный ранее XP не превращает первый заезд с ботами
в гонку против максимального тюнинга.

Проверки в Editor: границы всех ступеней; три стоковых бота при счётчике 0;
поздний временный бот (ступень 5, мощность x1.25, один активный спойлер и
один бампер); повторное Apply без повторного усиления; сохранение ключей
игрока; поражение не засчитано, успешный финиш засчитан только один раз.
Тестовые баланс, XP, рекорд и счётчик завершений восстановлены.

Resources/ModeRoutes.asset ссылается на готовый спринт и CityCircuitRoute.
Кольцо построено по существующему замкнутому дорожному маршруту трафика
(около 665 м), без копирования компонентов трафика в игровой маршрут.
Пересоздание: Tools → Burnout Drift → Create Mode Routes.

### Дополнительные проверки соперников

- В CityDay создаются три локальных физических автомобиля, активная машина
  и камера остаются у игрока; Photon-компоненты у соперников отсутствуют.
- В самостоятельном прогоне Sprint два бота прошли полный маршрут и
  финишировали примерно за 85 и 86 секунд. Остальные участники при этом
  продолжили заезд; игрок не получил награду за чужой финиш.
- У третьего префаба обнаружен конфликт ESP/TCS с тягой; без этих помощников
  автомобиль самостоятельно продвигается по маршруту. Настройка закреплена
  только для ботов, без изменения префабов и управления игрока.
- Отдельная автоматическая проверка Circle с перемещением бота по точкам:
  после 1/2 кругов завершения нет, после 3-го — есть; заезд игрока активен,
  баланс не изменяется.
- Проверка финиша игрока с перемещением по точкам Sprint: пропуск точек
  заблокирован; таблица содержит Aki/Kai/You/Ren, реальные времена и DNF,
  позиция игрока учитывает уже финишировавших ботов. Тестовые награды и рекорд
  восстановлены. Четыре строки проверены в Game View.
- Исправлена утечка анимаций ChangeButtonSelector при отключении меню:
  после смены сцены они больше не обращаются к уничтоженному RectTransform.
- После окончания заезда canControl у всех ботов отключён; после перехода
  в Main Menu экземпляров BD_RaceBot в сцене нет (проверено в Editor).
- Финальная компиляция: 0 ошибок. Оригинальная TMP-подпись SCORE заменяется
  на TIME, без дублирования шапки таблицы.

Полный самостоятельный проезд трёх кругов всеми ботами и баланс сложности
на всех машинах ещё не подтверждены. Это отдельная игровая проверка,
не равнозначная тесту счётчика кругов.

Это проверки запуска и логики, не ручной проезд всех маршрутов на всех
машинах. Баланс сложности, читаемость ворот на трассе и сетевой режим
требуют отдельной игровой проверки. Сборки/релизы не выполнялись.
